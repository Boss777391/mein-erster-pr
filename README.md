# mein-erster-pr

Übungs-Repo für meinen ersten Pull Request.

## Worum geht's hier?

Dieses Repository dient zum Üben des GitHub-Workflows: einen Branch erstellen,
eine Änderung committen, pushen und einen Pull Request öffnen.

## Ablauf eines Pull Requests

1. Branch erstellen (`git checkout -b meine-aenderung`)
2. Änderung vornehmen und committen
3. Branch pushen (`git push -u origin meine-aenderung`)
4. Pull Request auf GitHub öffnen
5. Review abwarten und mergen
